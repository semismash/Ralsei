Welcome to **Rust As a Language for Synthesizing Extensible Integrated Circuits**, i.e. ***Ralsei*** (yes, the same name as a the fluffy darkner from *DELTARUNE*). ***Ralsei*** is a Rust crate meant for synthesizing and simulating hardware circuits within the Rust programming language, to allow for seamless integration with existing Rust projects, blazingly fast simulation speeds by leveraging the language's fast runtime performance, and fluid testing using Rust's inbuilt testing features.
***Ralsei*** positions itself to be a fast and easy to integrate library which aims to accurately simulate digital circuits in a software form, while remaining very fast and highly customizable, aiming to drastically reduce development times while keeping accuracy high.
